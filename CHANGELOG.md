# Changelog

## 0.1.0 (unreleased)

- One-way Google Drive mirrors for selected local folders on Linux.
- Journaled backup runs with resumable and checksum-verified uploads.
- Source marker, subtree membership checks, deletion brakes, and
  trash-only deletes with per-run undo.
- Preview, run history, mirror verification and repair, and setup diagnostics.
- Bilingual command-line interface and Textual dashboard.
- Personal Google OAuth desktop client setup and a daily systemd user timer.
